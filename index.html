Plan your conference

Conference Maker uses your accepted-paper total, number of panel rooms and usual timings to help you see the trade-offs. These are recommendations, not restrictions.

104 accepted papers≈ 35 three-paper panels
3 parallel rooms≈ 12 panel rounds
4 parallel rooms≈ 9 panel rounds
5 parallel rooms≈ 7 panel rounds

More parallel sessions create more space for keynotes, workshops, roundtables and longer breaks, but give delegates more simultaneous choices. Fewer parallel sessions reduce competing panels but require more panel rounds. You can also lengthen lunch on a particular day to make room for a lunchtime roundtable.

Academic panels must finish by 18:30. Conference Maker will help you adjust panel numbers, parallel sessions, events and breaks so the programme fits within that boundary.

3. Arrange Programme

Use the timetable generated in Set Up Conference. Drag panels for speed, or use the smaller Move… control.

Backup & restore: “Save in this browser” keeps a working copy on this computer. “Download backup” creates a portable conference file; “Restore backup” reopens one. “Number panels by timetable order” assigns final panel references from the current schedule.
Day colours — Host Editor only

Choose colours that help you distinguish working days. These colours are only an organising aid in the Host Editor and do not set the public conference design.

Move panel
Choose the destination day, panel session and room. If another panel is already there, the two panels swap safely. Nothing is deleted.

Things to place

Panels and events waiting to be scheduled. Drag an item onto the programme.

Automatic placement

What this does: Conference Maker places panels you have already built into available rooms and panel times. It avoids known speaker conflicts and respects locked events. You can review and move every panel afterwards.

It does not build panels or decide which papers belong together.

Speakers and chairs will be collected automatically in People.
