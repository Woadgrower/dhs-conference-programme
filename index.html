Conference details

Conference dates

Day labels and the year are generated automatically from these dates.

Standard working hours

These defaults apply to all days. You can make an exception later if one day genuinely differs.

▸ Day-specific exceptions
Optional. Keep this closed unless a day needs different hours.

Usual timings

Off by default. Enable only if the conference may deliberately schedule exceptional panels longer than the usual session. Standard panels still contain a maximum of 3 papers.

Conference Venues

Buildings used for the main academic conference. You can add more than one Conference Venue. Rooms added here become available for panels in Arrange Programme.

▸ Advanced room availability
Optional exceptions only. Standard setup assumes conference rooms are available during conference hours.

External Venues

Places used for receptions, dinners, tours, screenings or other offsite events. External Venues do not create panel-room columns in the academic timetable.

4. Arrange Programme

Use the timetable generated in Set Up Conference. Drag panels for speed, or use the smaller Move… control.

Portable backup: Save demo stays in this browser. Export conference file creates a separate JSON file you can keep anywhere and later restore with Import.
Day colours — Host Editor only

Choose colours that help you distinguish working days. These colours are only an organising aid in the Host Editor and do not set the public conference design.

Move panel
Choose a day, then click the destination room/time. If another panel is already there, Conference Maker will ask whether to swap them. Nothing is deleted.

Things to place

Panels and Events waiting for a time and place. Drag the divider to change the docked tray width. Open the tray in a separate browser window if you want to move it onto another part of your screen or another monitor. The × on the timetable only unschedules an item; permanent deletion is available here for Events.
